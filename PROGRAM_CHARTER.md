# Program charter

## Mission

Applied AI Training for Canada provides rigorous, accessible, 100% virtual learning in Applied AI, Cybersecurity GRC, AI Governance, and Cloud. SozoRock Tech Inc Canada operates the initiative from Ontario for learners across Canada.

The program protects learning quality, evidence, safety, accessibility, privacy, portability, and accountable review.

## Operating profile

- Operator: **SozoRock Tech Inc Canada**.
- Program: **Applied AI Training for Canada**.
- Delivery: Canada-wide and 100% virtual.
- Primary operating province: Ontario.
- Regional context: British Columbia, including Abbotsford.
- Price: free.
- Launch record: certificate of attendance and participation record.
- Status: training initiative; not a degree, diploma, licence, or accredited provider.
- Curriculum: fundamentals-first, problem-led, studio/lab, critique, evidence, and defense.
- Data reference region: AWS Canada Central for applicable program data, governed by approved provider, data-flow, retention, and deletion records.
- Collaboration: Google Drive is a sharing layer; versioned source and evidence remain canonical.
- Models: Codex, Grok, and Google models connect through replaceable provider adapters.

## Public language

Public copy uses the exact operator name, program name, delivery scope, price, and launch record. It excludes claims of accreditation, certification, endorsement, affiliation, licensing, immigration eligibility, study-permit eligibility, employment, promotion, or competency unless an approved evidence record and authorization support the claim.

## Automation and accountability

The standard learner path is automated across intake, consent, onboarding, reminders, session packets, labs, attendance, submissions, feedback routing, attendance records, quality reports, and funder reports.

Human authorization remains required for safety incidents, accessibility exceptions, assessment appeals, credential decisions, policy changes, and external claims. Automation supplies routing, evidence packets, deadlines, notifications, and audit history.

## Source and delivery rules

- `main` contains releasable source.
- Feature branches use one bounded scope: `feat/<scope>`, `fix/<scope>`, or `docs/<scope>`.
- Each commit represents one reviewable decision.
- Approved atomic commits are pushed after local validation.
- Release publication requires the configured checks and human gates.

## Provider portability

Provider-specific code stays behind an adapter. Curriculum, learner records, evidence identifiers, event types, and export formats remain usable when a model, cloud, collaboration, or credential provider changes.
