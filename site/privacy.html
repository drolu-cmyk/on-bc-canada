Privacy

Data minimization starts on the public page.

This public information shell contains no live learner intake.

What these pages do

  • Serve static program, curriculum, accessibility, support, privacy, and terms information.
  • Use no account creation, application form, learner workspace, or personal-data field.
  • Use no analytics form or advertising tracker in the repository-hosted shell.
  • Load local styles and a local year script without external model or marketing services.

Program data boundary

Program data uses defined privacy classes, provider inventories, retention rules, deletion routes, and human authorization. AWS Canada Central is the reference region for applicable program data. Deployment evidence governs the live service configuration.

Enrollment status

Enrollment is not active in this release. The shell does not request, store, or transmit learner information.
