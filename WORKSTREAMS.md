# 19 specialized workstreams

The lead maintains the shared context, branch rules, release gates, and integration order. Each workstream owns a bounded output and must return evidence, acceptance tests, dependencies, and risks.

## Integration order

1. Control plane, context, schemas, and policies.
2. Curriculum compiler and Common Core specifications.
3. Learner/instructor/virtual-delivery workflows.
4. Safe labs, data/privacy, and provider adapters.
5. Assessment, credentials, accessibility, and quality evidence.
6. Funding reports and public launch surface.

## Workstream handoff contract

Every workstream handoff must state:

- decisions made;
- files or contracts created;
- acceptance tests;
- dependencies;
- risks and unresolved questions;
- what is explicitly out of scope.
